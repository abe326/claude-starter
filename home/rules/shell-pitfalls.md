# シェルでつまずきやすいところ

## 見張りで `pgrep -f` を使わない

- 終了を待つループで `pgrep -f 'rsync -a.*backup'` のようにパターンを書くと、ループを実行しているシェル自身のコマンド行にも一致し、「まだ動いている」と判定し続ける
- `pgrep -x rsync`（プロセス名の完全一致）か、先に PID を取って `kill -0 <PID>` で判定する。パターンを使うなら `[r]sync` のように 1 文字を括弧で囲む

## zsh では変数に入れたコマンドが分割されない

- `C="sudo -u x env A=b"; $C cmd` や `N="python3 new.py"; $N …` は、zsh では全体が 1 つのコマンド名になり「no such file or directory」で失敗する。結果を grep で絞っていると、何も出ずに成功したように見える
- 複数語のコマンドは変数に入れない。繰り返すなら bash のスクリプトにするか、Python の subprocess にリストで渡す。ユーザーに渡すコマンドも同じ
