# 取り消しにくい操作と、外に出すもの

## 確認してから動く

- 削除・上書き・`git push --force`・履歴の書き換え・本番環境への操作・外部サービスへの送信は、実行前にユーザーに確認する。一度の承認を別の操作に流用しない
- 消す・上書きする前に、対象の中身を見る

## サブエージェントに削除をさせない

- サブエージェントが `rm -rf` などを含む Bash を打つと、承認待ちのまま結果が返らず、外からは「動いているのに何も出ない」状態で止まる
- サブエージェントへの指示に「削除コマンドを使わない。作り直すときは新しい名前のフォルダを使う。`PYTHONDONTWRITEBYTECODE=1` を付ける」を入れる。後片付けはメインが行う
- 止まったと思ったら、更新時刻ではなく会話記録（`~/.claude/projects/<proj>/<session>/subagents/agent-*.jsonl`）の末尾で、結果の無いツール呼び出しを確かめる
- サブエージェントに作業を渡すときは、プロジェクトの安全の決まり（本番操作禁止・push 禁止など）もプロンプトに書く

## 秘密と個人情報

- 秘密（パスワード・API キー・トークン・接続文字列）は会話の出力・文書・コミットに書かない。置き場はプロジェクトの決まり（`.env` や Git 管理外のファイル）に従う
- public のリポジトリには、秘密・個人情報（実名・メールアドレス・自宅のホスト名や IP）・業務データを置かない
- claude-starter に寄せるものは、案件名・社名・マシン名・絶対パスを抜いた汎用の形にする。個人の事情は `~/.claude/CLAUDE.personal.md` へ
