# 確認依頼一覧

相手（発注側・顧客・レビュアー）に**確認・判断・対応をお願いしたいこと**を 1 か所に集める。「今お願いしたいことだけ」を上に置き、片付いたものは履歴節へ移す。
ここは**相手向けの文面**。問いの中身・期限・決める人の正本は課題 md（`01_タスク管理/`、kind=課題）で、ここはそれを相手に見せる言い方で 1 行にしたもの。

- **書式**: `- [ ] **何が変わった／何を決めてほしい** — 開く場所: … ／ OK の状態: …（日付 / 課題かタスクの ID）`
- **ID は必須**: 各行に課題かタスクの ID を書く（先に `new.py` で起票し、出力の ID を写す）。ID の無い行・存在しない ID は `scripts/check_drops.py` が数える
- **凡例**: `[ ]` 未確認 ／ `[x]` 確認済（→ 履歴へ） ／ `[~]` 取り下げ（→ 履歴へ）
- **更新**: 依頼が生まれたら 1 行足す。回答を得たら**課題の `## 決定` を書いて閉じてから**（`close.py <ID>`）、行を `[x]` にして履歴へ移す。実名の誰の返事を待っているかは `案件情報.md` §4
- 秘密（URL・ID・パスワード）は書かない。開く場所は画面名・メニュー名で示す
