# decisions（ADR）

設計判断を 1 判断 1 ファイルで残す。ファイル名は `ADR-NNN-<短い英語>.md`（`ADR-001-naming.md` 等）。型は `ADR-000-テンプレート.md`。節は Status / Context / Decision / 却下した案 / Consequences / 関連。

## 索引

|:--|:--|:--|:--|

## 運用

- タスク md に書いた判断のうち、**複数タスク・複数領域に効くもの**を昇格して ADR にする。タスク内で閉じる判断はタスク md の「過去の経緯」で十分
- 状態は 提案 → 採用 → （置換 / 廃止）。置換したら新旧の両方に相手の番号を書く
- ADR を足したら本索引と、`docs/プロジェクト概要.html` の「直近の決定」（`update-overview` スキル）を同じ作業で更新する
- 秘密（URL・ID・パスワード・鍵）は書かない
