## 0. 位置づけ

利用者（`01-概要.md` §2 のロール）が製品をどう使い、当方がどう支えるかの方針。利用者に見せる**固定文の正本は §5**。

`未決`・`提案` の項目を根拠に「方針に反する」と指摘しない。`決定` に実装が反していれば実装側を直す（`04-原則.md` §3）。

## 5. 障害時の利用者向け対応

| 段階（09 §4） | 固定文 | 告知経路 | 誰が出す（SH-xx） | 状態 |
|:--|:--|:--|:--|:--|
| 正常 | — | — | — | 決定 |
| | | | | |

（例）`縮退 | 「一部の機能を一時的に停止しています。閲覧は可能です。復旧まで今しばらくお待ちください」 | 画面上部のバナー | SH-01 | 提案`
