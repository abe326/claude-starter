# 03 関係者 — 誰と決めるか
> 最終更新: 2026-10-01（初版。雛形のまま）／ 対象: —
> 作成: 2026-10-01 ／ 位置づけ: 案件の関係者ロール・判断権限・確認の取り方・NG 事項の正本 ／ 対象読者: Claude Code・担当者
> 扱わないもの: 製品の利用者ロール → `01-概要.md` §2、実名・連絡先・日程 → `案件情報.md` §1（Git 管理外）、個別の確認事項 → `docs/案件/確認依頼一覧.md`

## 0. 位置づけ

案件の**関係者をロール**（SH-xx）として定義し、「誰が何を決められるか」「どう確認を取るか」「誰に何を言わないか」を持つ。製品を使う人のロールは `01-概要.md` §2。実名・連絡先・日程は `案件情報.md` §1（Git 管理外）が持ち、本書の SH-xx を同書 §1 の「ロール ID」列で引く。

`未決`・`提案` の項目を根拠に「方針に反する」と指摘しない。`決定` に実装が反していれば実装側を直す（`04-原則.md` §3）。

## 1. ロール一覧

ロールは役割であって人ではない。1 人が複数ロールを兼ねてよい。「決められないこと」を必ず書く（空欄は「何でも決められる」と読まれる）。区分は 当方 / 発注側 / エンド顧客 / 外部ベンダー。

| ID | ロール名 | 区分 | 関心事 | 決められること | 決められないこと | 状態 |
|:--|:--|:--|:--|:--|:--|:--|
| SH-01 | 実施担当 | 当方 | 品質・納期・作業負荷 | 進め方・手段の選定・作業順 | 仕様の変更・公開の可否・費用 | 決定 |
| | | | | | | |

（例）`SH-02 | 発注側の窓口 | 発注側 | 予算・期日・顧客との合意 | 仕様変更の可否・期日 | エンド顧客のデータの扱い | 提案`
（例。運用保守）`SH-03 | 運用の当番 | 当方 | 障害対応・定常作業の抜け | 一次対応の手順の選択 | 運用範囲の変更・費用 | 提案`

## 2. 判断権限マトリクス

行が事項、列がロール。セルは 決める / 相談 / 報告 / 不要 のいずれか。「決める」は各行に 1 つ。空欄は未決（課題に起票し、セルに「（未決 <課題ID>）」と書く）。

| 事項 | SH-01 | SH-02 | SH-03 |
|:--|:--|:--|:--|
| 仕様変更 | 相談 | | |
| 期日 | 相談 | | |
| 費用 | 報告 | | |
| 公開・リリース | 相談 | | |
| データの扱い | 相談 | | |
| 外部連携の追加 | 相談 | | |

## 3. 確認の取り方

ロールごとに「どの経路で・どの形式で・どれくらい待つか・どこに残すか」を持つ。個別の確認事項そのものは `docs/案件/確認依頼一覧.md`。

| ロール | 経路 | 形式 | 期待リードタイム | 記録先 |
|:--|:--|:--|:--|:--|
| SH-01 | 直接 | タスク md | 即日 | タスク md「過去の経緯」 |
| | | | | |

（例）`SH-02 | 発注側の窓口へ直接 | 確認依頼一覧 → 週次打合せ | 1 週間 | docs/案件/確認依頼一覧.md → docs/案件/02_打合せ/`

**先に聞かずに進めてよい範囲**（ここに無いものは確認依頼一覧に載せてから進める）:

- §2 で SH-01 が「決める」となっている事項
- 決定済みの仕様の範囲内での進め方・手段の選択
- （例）意味と用語（`01-概要.md` §6）が変わらない文言の軽微な修正

## 4. NG 事項

ロールごとに「言わない・見せない・送らない」を持つ。利用者向け文面の規約は `08-利用者の運用.md` §6、秘密の扱いは `.claude/rules/secrets.md`。

| ロール | 言わないこと | 見せないもの | 送らないもの | 状態 |
|:--|:--|:--|:--|:--|
| 全ロール（当方以外） | — | `環境情報.md` の値・`.work/機密/` の資料 | 資格情報・接続文字列 | 決定 |
| | | | | |

（例）`SH-03（エンド顧客） | 基盤の製品名・他社案件 | 内部の見積・進捗の生データ | 打合せ記録そのもの | 提案`

## 5. 利用者ロールとの対応

`01-概要.md` §2 の利用者ロールが、案件の関係者のどれに当たるか。対応が無い利用者ロール（一般利用者等）は「—」。

| 利用者ロール（01 §2） | 関係者ロール | 備考 |
|:--|:--|:--|
| | | |

（例）`管理者 | SH-03 | 権限の付与・剥奪は 08 §2`

未決は課題 md が正本（`docs/案件/01_タスク管理/`、kind=課題）。本文からは「（未決 QA-01）」で参照する。本書に関わる未決は `python3 scripts/check_drops.py --refs 03` で一覧
