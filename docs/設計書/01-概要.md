## 1. 目的

Claude Code の初期セット。~/.claude に入れる汎用の決めごと・skill・rules・hooks と、プロジェクトから育てて自動展開する仕組み

Claude Code を複数のマシン・複数のプロジェクトで使っていると、`~/.claude` の決めごと・skill・設定がマシンごとにずれ、プロジェクトで見つけた改善も他へ広がらない。さらに `~/.claude` には個人の事情が混ざっているため、そのままでは人に渡せず、本業など別の環境へも持ち込みにくい。

claude-starter は `~/.claude` を「公開できる汎用部（このリポ）」と「各マシンだけの個人部」に分け、汎用部をリンクで配る。プロジェクトで直したものは候補として自動で集まり、承認したものだけを汎用の形に書き直して取り込み、公開前検査を通して公開する。各マシンにはリンク・同期・`git pull` で自動的に行き渡る。

## 3. スコープ

### 含むもの

- `~/.claude` の汎用の決めごと・rules・skills・settings・status line・hooks（`home/`）
- 展開・同期（`scripts/starter.py install`／`sync`）、Windows のジャンクション対応
- プロジェクトからの候補の収集（Stop hook）と取り込み（`promote` スキル）
- 公開前検査（`scripts/check_public.py`）と CI

### 含まないもの（非スコープ）

- 案件フォルダの型（project-skeleton が担う）
- Claude Code 以外のツール（GitHub Copilot CLI など）向けの設定
- Anthropic 製の skill の再配布
