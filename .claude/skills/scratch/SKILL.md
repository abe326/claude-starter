# scratch

「あとから捨ててもよい前提」のファイルを、どこにどう置くかを決めるスキル。ルート直下・`.work/` 直下・`.work/一時/` 直下に PNG / JSON / SQL / log / md を散らかすことを禁止する。

どの枠（一時 / 証跡 / 機密）へ置くかの判断は `.claude/rules/work-area.md` が正本。本スキルは「`一時/` に置くと決まったあと」の命名と作法に責務を絞る。

## 適用タイミング

次のようなファイルを生成・保存する**直前**（`Write` / `Bash > redirect` / スクリーンショットの `filename` を決める段階）。

- 質問への長文回答・比較表・選択肢の整理を md や html にまとめるとき
- ユーザーに確認してもらうためのドラフト（文面・表・図）
- 動作確認のログ・スクリーンショット・API レスポンスの保存
- デバッグ用の一時 SQL / CSV / JSON ダンプ
- 試し書きのスクリプト・検証用 HTML
- 「あとで消す」「動作確認用」「使い捨て」と自分で意識しているとき

## 前提: そもそも `一時/` でよいか

**判断基準は「半年後に読み返す価値があるか」。** Yes ならタスクに紐づけて `docs/案件/`（タスク md 併置）か `.work/証跡/<ID>_内容/`（`work-placement` スキル）。No なら本スキルの `.work/一時/`。迷ったら `証跡/` に寄せる。

`一時/` に置かないもの: 合意した実装計画・設計判断・ADR・打合せ記録・提出資料・タスク md から参照する証跡。

## 配置ルール

```
.work/一時/YYYYMMDD_用途/
```

- `YYYYMMDD` は作業日。同じセッションで複数生成するなら同一フォルダにまとめる
- `用途` は日本語 2〜6 語（例: `20260101_比較表`、`20260101_ログイン確認スクショ`、`20260101_移行案ドラフト`）
- `temp/` `debug/` `tmp/` のような日付なし・用途なしの名前は禁止（hook が止める）
- `.work/一時/` 直下にファイルを直接置かない（必ずサブフォルダ経由。hook が止める）

## 作法

1. **md / html の先頭に注記を入れる**

   md:
   ```
   > 一時資料（claude-starter・YYYY-MM-DD）。予告なく削除される。正本ではない。
   ```
   html: `<body>` 直後に同じ文言を 1 行（`<p class="note">…</p>`）
2. **HTML は単一ファイル**（CSS / JS 内蔵、外部 `<script src>` / `<link href>` を使わない）。開くだけで見られる状態にする
3. **秘密を書かない**（URL・ID・パスワード・鍵。`.claude/rules/secrets.md`）。ログやスクショに写り込んでいないか保存前に確認する
4. **作成後に必ずパスを提示する**。ユーザーが開けるよう絶対パスで示す
5. **「残す」と言われたら移す**。`.work/証跡/<ID>_内容/` か `docs/案件/`（タスク md 併置）へ移動し、`.work/README.md` の対応表に 1 行足す。`一時/` に置いたままにしない

## 禁止事項

- プロジェクトルートに PNG / SQL / JSON / log / md を直接書く（hook が止める）
- `.work/` 直下・`.work/一時/` 直下にファイルを直接置く（hook が止める）
- サブフォルダ名を日付なし・用途なしにする（`temp/` `debug/` 単体）
- 合意した計画・設計判断・証跡を `一時/` に入れる（→ タスク md / `証跡/`）
- 一時資料に秘密の実値を書く
- パスを提示せずに作成を終える
