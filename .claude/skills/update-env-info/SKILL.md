# update-env-info

`環境情報.md`（URL・アカウント・資格情報・環境変数・ドメイン）と `案件情報.md`（関係者・案件の状態・公開しない日程・実名の返事待ち）は、ルート直下にある **Git 管理外の正本**。ここが古いと、次のセッションが古い前提で動く。変化があったら**同じ作業の中で**更新する。

## 発火条件

### `環境情報.md`

- 環境の作成・削除・URL 変更（§1・§2）
- ユーザー・ロールの追加・変更・削除（§3）
- CLI・SSH・MCP などアクセス手段の変更（§4）
- 環境変数の追加・削除・意味の変更（§5。`.env.example` と対）
- ドメイン・DNS・証明書の変更（§6）
- 未取得・未確認だったものが解決した、または新たに生じた（§7）

### `案件情報.md`

- 関係者の追加・役割変更（§1）
  - ロールそのものが増えた・判断権限が変わったら `docs/設計書/03-関係者.md` も同じ作業で直す（`sync-design-docs` スキル）。§1 の「ロール ID」列は同書 §1 の SH-xx
- 案件の状態・いまの位置・次の期日・待っているものの変化（§2）
- 公開しない日程（先方の社内事情・未公表の日付・個人の予定）の追加・変更（§3）。公開してよい節目は概要 HTML のロードマップ（`update-overview` スキル）、締切はタスク・課題の `due`（`task` スキル）が正本なので、ここには書かない
- 誰の返事を待っているか（実名の対応）の発生・解消（§4）。問いの中身・期限・決める人は課題 md が正本。**未決を §4 に起こさない**: 先に課題を起票し（`task` スキル。ID は `new.py` の出力の 1 行目から写す）、§4 には「課題・タスク ID / 誰の返事か（実名）/ 経路」だけを書く。課題・タスクを閉じたら行を消す

### 共通

- 読んでいて実態とずれていると気づいたとき（気づいた人がその場で直す）
- ユーザーが「環境情報を直して」「案件情報を更新して」等と言った

## 手順

1. **対象ファイルを Read する**（全体。どのセクションに書くかを既存の表の形に合わせる）
2. **該当セクションだけを上書きする**。日付別ファイル・「新版」ファイルを作らない。古い値は消して新しい値に置き換え、経緯が要るなら 1 行の注記（「YYYY-MM-DD 変更: 旧 → 新」）にとどめる
3. **改訂履歴に 1 行足し、冒頭の「最終更新」を今日にする**（`環境情報.md` は末尾の改訂履歴表、`案件情報.md` は冒頭の最終更新）
4. **環境変数を触ったら `.env.example` と §5 を同期する**。変数名・意味・値の所在が両方で一致していること。値は `.env.example` に書かない
5. **概要 HTML の「5. 構成図と環境の入口」に影響するなら `update-overview` スキルを続けて実行する**（環境の追加・削除・用途変更）。URL・秘密は概要 HTML に書かず「環境情報.md §n 参照」とする
6. **タスク ID を関連付ける**。`案件情報.md` の関連タスク列、`環境情報.md` §7 の関連タスク列に ID を入れる

## 値の扱い

- 実値（URL・ID・パスワード・鍵・接続文字列）を書けるのは `環境情報.md` と `.env` だけ（`.claude/rules/secrets.md`）
- `案件情報.md` には値を書かない。正本へのリンク（「`環境情報.md` §2.1」）にする
- **会話の出力へ値を転記しない**。「`環境情報.md` §n に書いた」と伝える
- ツールが値の取得を拒否した・取得できなかったものは §7「未取得・未確認」へ理由付きで書く

## 禁止事項

- 日付別ファイル・複製を作る（`環境情報_20260101.md` 等）
- 変化に気づいたのに「後でまとめて」と先送りする
- `.env.example` と §5 を片方だけ直す
- 概要 HTML・docs・タスク md・会話出力へ実値を写す
- 改訂履歴・最終更新を更新せずに本文だけ変える
- 未決の問い・期限を `案件情報.md` §4 に書く（課題 md が正本。§4 は ID と実名の待ちだけ）。チームに見せてよい節目・締切を §3 に書く（ロードマップと `due` が正本）

## 関連

- `環境情報.md` / `案件情報.md` — 対象（ルート直下・Git 管理外）
- `.env.example` — 変数名と意味の見本（§5 と対）
- `.claude/rules/secrets.md` — 秘密の取り扱い
- `.claude/skills/update-overview/SKILL.md` — 概要 HTML の「環境の入口」
