# 作業領域（`.work/`）の配置ルール

## 原則

`.work/` は Git 管理外（`.gitignore`）の作業領域。**枠は「消してよいか」と「誰が参照するか」の 2 軸で決まる**。「一時ファイル置き場」という単一の理解で運用すると、タスク md から参照される証跡が使い捨て扱いで退避され、参照が黙って切れる。

過去の事故: 別プロジェクトで `.work/` 直下を `_bk/` へ一括退避し、タスク md からの参照が 47 本切れた。後続タスクは「ファイルは現存しない」と誤結論して作業をやり直した。本ルールはこの再発を止めるためのもの。

## 適用タイミング

- `.work/` 配下へファイル・フォルダを**生成**するとき（出力先パスを決める段階）
- `.work/` 配下を**移動・退避・整理**するとき
- `.work/` 配下のパスを**参照して見つからなかった**とき

## 枠の定義と判断フロー

上から順に判定し、最初に Yes になった枠へ置く。

| 問い | Yes → 置き場 |
|---|---|
| 仕組み（hook / skill / script）がパスを固定して読み書きするか | **直下**（`README.md` と `.work/README.md` §1 に列挙したものだけ） |
| 外部から受領した一次資料そのものか（契約書・決算書・名簿・未公開資料等） | **`機密/<タスクID>_内容/`** |
| タスク md から参照される／される可能性があるか | **`証跡/<タスクID>_内容/`**（複数タスク共有は `YYYYMMDD_内容/`） |
| いずれも No（消してよい） | **`一時/YYYYMMDD_用途/`** |

- **直下は人が増やさない**。仕組みの固定パスを新設したときだけ、本ルールと `.work/README.md` の両方へ追記する。PreToolUse hook（`work_area_guard.py`）が直下への書き込みを止める。仕組みの固定パス（ルート直下のファイル・`.work/` 直下・`一時/` の日付の付かない固定フォルダ）は `.claude/project.json` の `work_area_allow` に glob で書くと hook が通す（hook のコードは書き換えない。追記はユーザーの承認後）
- `証跡/` と `機密/` の境界は「**こちらが作った成果物か、受領物そのものか**」
- `一時/` の唯一の定義は「**消してよい**」。後で使うものを置かない。サブフォルダ名は `YYYYMMDD_用途` で始める（hook が検査する）
- `_bk/` は移動・改名の前に取る退避コピーの置き場。参照元が無いことを確認してから消す

**迷ったら `証跡/` に寄せる。** `一時/` に入れて消える方が、`証跡/` に残って邪魔になるよりはるかに損失が大きい。

## 移動時の必須手続き

`.work/` 配下のパスを移動・退避したら、**同じ作業の中で** `.work/README.md` の「旧パス → 新パス 対応表」を更新する。更新しない移動は禁止。

移動の前に参照を確認する:

```bash
grep -rn "<旧パス>" .claude docs CLAUDE.md
```

**タスク md 側の参照パスは書き換えない。** `docs/案件/` は共有する過去記録であり、辻褄合わせのために過去の記述を改変しない。読み替えは `.work/README.md` の対応表が担う。

## 参照解決の規約（本ルールの核）

`.work/` 配下のパスが見つからないとき、**「存在しない」と結論する前に必ず `.work/README.md` の対応表を引く**。過去の整理で移動している可能性が高い。対応表にも無い場合に限り「存在しない」と判断してよい。

## 禁止事項

- 直下へ人がファイル・フォルダを直接置く（`README.md` と固定パスのみ）
- `証跡/`・`機密/` の中身を `一時/` へ退避する
- `.work/README.md` の対応表を更新せずに `.work/` 配下を移動・退避する
- タスク md 側の参照パスを書き換えて辻褄を合わせる
- `一時/` に「後で使うもの」を置く（`一時/` は予告なく削除される）
- `.work/` 配下のパスが見つからないことを、対応表を引かずに「存在しない」と結論する
- 受領した一次資料を `証跡/` や `一時/` に混ぜる（→ `機密/`）

## 関連

- `.work/README.md` — 実データの索引 ＋ 旧パス→新パス対応表
- `.claude/skills/work-placement/SKILL.md` — 作業着手時の振り分け（入口・どの枠かの判断）
- `.claude/skills/scratch/SKILL.md` — `一時/` 配下のサブフォルダ命名の細部
- `.claude/rules/docs-management.md` — `docs/案件/`（Git 管理・共有）との境界
- `.claude/hooks/work_area_guard.py` — 直下・`一時/` 直下への書き込みを止める hook
